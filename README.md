# ポートフォリオサイト（オリジナルWordPressテーマ）

**サイトURL:** [My Portfolio](https://cozy101.xsrv.jp/ishikawa/portfolio/)

ゼロからデザイン・コーディングを行い、WordPressのオリジナルテーマとして構築したポートフォリオサイトです。
保守性を意識した設計とモダンなフロントエンドの基礎力を意識して開発しました。

## ■ 使用技術
* **Frontend:** HTML5, SCSS, Vanilla JavaScript
* **Backend:** WordPress (PHP)
* **Architecture:** BEM

## ● コーディングにおける設計と思想

### 1. 完全コンポーネント化と保守性の追求（SASS / BEM）
他の開発者が理解しやすい構成を意識し、保守性を重視して設計しています。
機能ごとのファイル分割、変数管理、BEMによる命名規則を導入し、保守しやすいコンポーネント管理を目指しました。

### 2. 脱jQuery。Vanilla JSによる自走できる基礎力
モーダルやハンバーガーメニュー、スクロール連動アニメーション等の動的UIは、jQueryなどのライブラリに依存せず、すべてVanilla JSで実装しました。
裏側のDOM操作の仕組みから深く理解し、将来的なモダン環境（React等）にも柔軟に適応できるフロントエンドの土台作りを意識しています。

### 3. 安定性を意識したレスポンシブ設計
モバイルファーストを基本としたブレイクポイントによる緻密なレスポンシブ設計を行っています。
画像遅延読み込み（Lazy Load）によるパフォーマンス最適化や、実機端末・主要ブラウザ間でのクロスブラウザ対応を徹底し、環境に依存しない確実な品質を担保しています。

### 4. 静的コーディングからのオリジナルテーマ化
HTML/SCSS/JSでの静的なフロントエンド実装後、実際の運用を想定してWordPressのオリジナルテーマとして組み込みを行いました。
- ACFを利用して管理画面から投稿内容を更新可能
- カスタム投稿を利用して制作実績を管理
- PHPループによる動的出力を実装

### 5. 現在の学習・改善方針
本ポートフォリオ制作後も、Vanilla JavaScriptを中心に継続学習を行っています。
特に、DOM操作・イベント処理・配列操作・タイマー処理・UIコンポーネントの実装理解を深めることを目的に、基礎課題を反復しながら学習しています。
現在は、既存サイトの実装で使用したモーダル、ハンバーガーメニュー、スクロール連動処理などの理解を再確認しつつ、今後はタブUI、アコーディオン、Todoアプリなど、より汎用的なUI部品や小規模アプリケーションの制作にも取り組む予定です。
単にコードを写すだけでなく、処理の流れを自分の言葉で説明できること、保守しやすい構造で実装できることを重視して学習を進めています。

### 5. 継続学習について
ポートフォリオ制作後も、Vanilla JavaScriptを中心に継続学習を行っています。
現在はDOM操作、イベント処理、配列操作、タイマー処理などの基礎理解を深めながら、UIコンポーネントや小規模アプリケーション制作に応用できる力を身につけることを目標にしています。

今後は、タブUI・アコーディオン・Todoアプリなどの制作を通じて、実装パターンの引き出しを増やしていく予定です。
